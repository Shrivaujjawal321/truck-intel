# Data exports — samples

One CSV per database table, **first 1000 rows only**, ordered by the first
column so re-running the export reproduces the same rows rather than churning
the diff.

Generated by `scripts/export_csv.py`:

    uv run python scripts/export_csv.py --sample 1000 --out data/samples   # what is committed here
    uv run python scripts/export_csv.py                                    # the FULL export, ~4.6 GB

The full export is deliberately not in git. Four of its files exceed GitHub's
100 MB per-file limit — core.bridges alone is 2.4 GB — and every one of them
regenerates from the database on demand, so committing them would grow the
repository permanently for data that is rebuilt from source anyway.

Geometry columns are written as WKT, not the hex WKB that COPY emits by
default: a column full of `0101000020E6100000...` is not something a person or
a spreadsheet can use, which is the point of a CSV export.
